# 🦞 OpenClaw

OpenClaw는 모든 운영체제와 플랫폼에서 작동하는 개인 AI 어시스턴트입니다. 당신의 기기에서 실행되며, 당신이 통제합니다.

## 특징

- **로컬 우선** — 데이터는 당신의 기기에 머물며, 클라우드에 업로드되지 않습니다.
- **다중 채널** — Telegram, Discord, WhatsApp, Signal, iMessage 등을 지원합니다.
- **스킬 시스템** — 확장 가능한 스킬로 에이전트의 능력을 확장하세요.
- **메모리** — 장기 기억과 일일 노트로 세션 간 연속성을 유지합니다.
- **크론 작업** — 예약된 작업과 알림을 자동화하세요.
- **서브에이전트** — 병렬 작업을 위한 격리된 세션을 생성하세요.

## 빠른 시작

```bash
# 설치
curl -fsSL https://openclaw.ai/install.sh | bash

# 온보딩
openclaw onboard --install-daemon

# 대시보드 열기
openclaw dashboard
```

자세한 내용은 [시작하기](/ko/start/getting-started)를 참조하세요.
