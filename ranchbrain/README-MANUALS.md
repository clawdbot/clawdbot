# RanchBrain Manual Library

Place manuals in the folders below.

Examples:

manuals/
├── Toyota-4Runner/
├── Kubota/
├── John-Deere/
├── Ecobee/
├── Eufy/
├── Sonos/
├── Lorex/
├── Pool/
├── Jacuzzi/
├── Well/
├── HVAC/
└── Generator/

Supported formats (current):

- .txt
- .md

Planned:

- PDF
- DOCX
- HTML
- Images with OCR
