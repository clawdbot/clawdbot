# RanchBrain Modules

RanchBrain is the long-term memory system for RedBud Ranch.

Modules:

- system: OpenClaw, servers, backups, watchdogs
- property: land, equipment, pool, generator, repairs
- budget: household, Lori, Andy, ranch/property finances
- health: glucose, BP, medications, appointments, nutrition
- projects: active and historical projects
- homeassistant: sensors, automations, device history
