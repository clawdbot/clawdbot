## Diagnostics design

The shared validator now records the overlong basename failure as an internal structural shape containing:

- `attachmentIndex`
- measured UTF-8 `basenameBytes`
- canonical `maxBasenameBytes=255`

The continuation redactor accepts only the exact anchored overlong-basename shape. It verifies that the maximum equals `MAX_INLINE_ATTACHMENT_BASENAME_BYTES`, the measured value is a safe integer, and the measured value exceeds the maximum. It then reconstructs the diagnostic from those approved numeric fields and the compiled constant. It never returns the basename, content, path, mount destination, receipt identifier, or arbitrary raw error text.
