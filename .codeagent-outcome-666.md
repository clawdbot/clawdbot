## Corrective scope

- Route delegate-artifact filesystem operations through the OpenClaw
  `fs-safe` policy boundary and reject materialization into read-only sandbox
  workspaces.
- Preserve one completion enqueue and one chain-cost step for targeted text
  fanout while retaining per-recipient text and provenance.
- Complete the `prepareFormattedSystemEvents` test mock required by the
  current reply-run contract.
- Authorize continuation and artifact tools against the live run-session key,
  with dedicated session-key regressions.
- Preserve return options and recipient context through post-compaction
  staging.
- Centralize managed TaskFlow rejection and policy cleanup.
- Terminalize stale and overflow managed delegates rather than silently
  dropping them, while preserving authoritative TaskFlow state when requeue
  fails.
- Store durable delivery acknowledgement IDs in the recipient transcript
  before persistence so crash recovery can settle idempotently.
- Replace transcript acknowledgement IDs on every prompt rebuild so only
  managed events present in the final admitted prompt can be settled.
- Forward writable-sandbox capability through the top-level OpenClaw tool
  factory so artifact materialization is rejected only for read-only sandboxes.
- Terminally reject crash-orphaned post-compaction TaskFlows whose accepted
  artifact policy was never persisted, instead of retrying them forever.
- Wire delegate-artifact retention cleanup into gateway startup, maintenance,
  and shutdown.
