## #666 contract decision

The v1 unit is a **host-managed opaque artifact claim** bound to:

1. the exact producing delegate run;
2. an immutable causal completion event;
3. the dispatch and captured return-policy version; and
4. the complete intended recipient binding.

The host retains bytes privately. A recipient receives typed display metadata
and a host-authored arrival context; a claim ID is not itself permission to
retrieve or materialize bytes. Resolution is a separate, explicit,
recipient-authorized, auditable operation that rechecks current policy.

The arrival context is mandatory for every child-to-recipient delivery. For an
inter-session or silent enrichment target that never saw the dispatch, it must
identify delivery class/route, source/run/completion provenance, dispatch and
scheduled/completed/delivered/replayed time facts, policy version, current
claim lifecycle state, recipient authorization, and bounded declared purpose.
It must not turn caller context into host authority or fresh instruction.

## Explicit exclusions and honest current fallback

The current continuation completion route remains text-only. Until an accepted
#666 implementation exists:

- no `InlineAttachment[]` or raw `content` completion payload is adopted;
- no output is inferred from final prose, tool output, workspace paths/scans,
  hashes, arbitrary URLs, or `message(action=send, media=...)`;
- no child output is auto-mounted into a parent, prompt-injected, or uploaded
  to a channel;
- no opaque identifier, path, URL, or digest is treated as authorization; and
- no generic `data: JsonValue` return surface is introduced.

Text-only completion remains the honest fallback. A later implementation must
introduce an explicit host-bound publication mechanism for allowed regular
files, canonicalize and validate the output boundary, retain bytes under
policy, create immutable claims idempotently, and implement explicit resolution
and per-recipient delivery.

## Required acceptance before implementation

RFC Appendix A.6 requires proofs for normal parent return, zero-awareness
inter-session/silent enrichment, delayed/post-compaction temporal skew,
restart/replay idempotency, retention and cleanup, recipient isolation, and no
implicit promotion from prose/tool output/path/URL/media.
