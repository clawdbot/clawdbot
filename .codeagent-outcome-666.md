## Implemented behavior

- Omitted return options retain the existing text-only completion path.
- Accepted managed returns capture an immutable policy containing producer/run,
  dispatch revision and times, parent and exact recipient incarnations, route,
  purpose, output root, MIME/byte/count bounds, and retention deadline.
- Children explicitly publish bounded regular files only. Publication rejects
  symlinks, hardlinks, out-of-root paths, TOCTOU changes, unsupported MIME,
  oversized candidates, malformed captured policy, and disabled runtime.
- Finalization creates private non-bearer claims and per-recipient bindings.
  Prompt projection is the closed seven-field `ArtifactSummary` vocabulary and
  never exposes backing bytes, paths, URLs, hashes, or locators.
- Parent and no-awareness inter-session recipients receive host-authored arrival
  context with immutable producer/dispatch/completion/policy/recipient binding,
  actual first-delivery/replay times, and bounded inter-session purpose.
- Recipient operations are explicit `list`, `inspect`, `materialize`, and
  `discard`; every operation rechecks the acknowledged recipient incarnation,
  runtime/cross-session gates, retention, claim state, and backing integrity.
- Delivery queue records use a closed managed-delivery discriminator binding
  receipt, projection, expected session, dispatch, and recipient. Prompt drain
  revalidates durable state and current gates before exposure. Disabled work is
  left queued without acknowledgement or mutation.
- First attempt is recorded only after per-recipient durable ownership and a
  successful in-memory enqueue. Restart records replay ownership and rebuilds
  canonical context. Repeated durable acknowledgement IDs replace rather than
  duplicate prompt events.
- Transient direct and post-compaction spawn failures requeue managed work and
  arm bounded retry. Deterministic rejection terminalizes TaskFlow before
  policy cleanup; crash races preserve recoverable policy/provenance.
- New state is additive SQLite state in the shared database. No schema-version
  bump, public artifact download/locator API, configuration, environment
  variable, channel-media route, or #1192 parent-to-child snapshot change was
  introduced.

   bridge capability or an accepted pre-dispatch backend capability contract.
   That is the user-specified public-contract-widening stop condition, so this
   lane does not invent a fallback or claim complete remote support.

   secret scan but could not run the Codex model because the existing token was
   invalidated. No undocumented engine/model substitution was used.
3. **No generic fallback:** corrupt, expired, revoked, disabled, mismatched, or
   unavailable managed claims terminate/defer explicitly. They never fall back
   to paths, raw bytes, URLs, hashes, ordinary artifact download, or inferred
   prose/tool output.
