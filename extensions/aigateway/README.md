# OpenClaw AIgateway provider

Bundled provider plugin for [AIgateway](https://aigateway.sh) — 1,000+ models
from 85+ labs behind a single OpenAI-compatible endpoint at pass-through
provider pricing.

## Install

```sh
openclaw plugins install @openclaw/aigateway-provider
openclaw gateway restart
```

## Docs

See `docs/providers/aigateway.md` in the OpenClaw repository, or the published
docs at `https://docs.openclaw.ai/providers/aigateway`.
